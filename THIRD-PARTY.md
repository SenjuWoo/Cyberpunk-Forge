The forge ships no third-party code or game data.

- **PyYAML** (MIT) is installed as a Python dependency.
- The **RED4ext template** fetches RED4ext.SDK (MIT,
  https://github.com/WopsS/RED4ext.SDK) at build time; it is not vendored.
- File-format knowledge (archive index, TweakDB IDs and binary layout) was
  learned from the open-source WolvenKit (https://github.com/WolvenKit/WolvenKit)
  and RED4ext.SDK sources and confirmed against an installed game. No code was
  copied.

  Codeware, RED4ext, Mod Settings, Input Loader, Audioware, WolvenKit) refer to
